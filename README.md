# Optimal Flight Route Finder

**Find the shortest path between airports with distance, duration, and estimated price.**

---

## Features

- Select departure and destination airports.
- Interactive map with flight path animation.
- Distance, duration, and price calculation.
- Weather info for departure airport.
- Search history & clear history functionality.
- Dark & light theme toggle.

---

## Technologies Used

- HTML, CSS, JavaScript (Frontend)
- Leaflet.js (Map & markers)
- Select2.js (Dropdowns)
- Flask (Backend)
- NetworkX (Flight path calculations)
